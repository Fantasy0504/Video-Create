# 示例：二分查找

演示结构：**数组 + 双指针**。和斐波那契那个示例的画面结构完全不同，
但共用同一套引擎 —— 说明模板不只服务递归树。

```bash
python tools/render.py examples/binary_search/scene.py
```

## 本期任务卡

- **主题**：在有序数组里查找目标值，每轮排除一半区间。
- **学习目标**：观众能够解释"为什么每轮能丢掉一半，因此最多 log n 次比较"。
- **演示输入**：`a = {3, 7, 11, 18, 25, 33, 41}`，目标 `25`。
- **时长**：约 24 秒。
- **声音**：无配音、无背景音乐。

## 执行记录

维护 `lo / hi` 两个闭区间端点，每轮看中点：

| 轮 | lo | hi | mid | a[mid] | 判断 | 动作 |
|---|---|---|---|---|---|---|
| 1 | 0 | 6 | 3 | 18 | 18 < 25 | `lo = mid + 1 = 4` |
| 2 | 4 | 6 | 5 | 33 | 33 > 25 | `hi = mid - 1 = 4` |
| 3 | 4 | 4 | 4 | 25 | 命中 | 返回 4 |

比较次数 3 次。若区间为空则返回 `-1`。

## 画面说明

- 数组沿索引横向展开，**不显示下标**（避免和指针标签打架）。
- `lo` / `hi` / `mid` 三个指针用箭头指向目标格子，`mid` 的箭头放低一层，
  和 `lo`/`hi` 重合时不会叠在一起。
- 被排除的中点短暂转红（PRD 2.2：需要特别注意的代价），命中后整格转绿，
  其余格子变暗，把注意力收拢到结果上。

## 分镜

| 场景 | 内容 |
|---|---|
| 一 | 标题 + `target = 25` |
| 二 | C++ 代码 + 数组出现，初始 `lo = 0, hi = 6` |
| 三 | 三轮比较：mid 定位 → 判断 → 收窄区间 |
| 四 | 结论：`a[4] = 25`，时间 `O(log n)`、空间 `O(1)` |
