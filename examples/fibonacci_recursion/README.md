# 示例：斐波那契数列 · 非记忆化递归

演示结构：**递归调用树**。展示 `fib(5)` 的调用、返回与重复计算。

```bash
python tools/render.py examples/fibonacci_recursion/scene.py
```

## 本期任务卡

- **主题**：从 `fib(5)` 看懂非记忆化递归的调用、返回与重复计算。
- **学习目标**：观众能够解释"先向下调用，子调用返回后求和；相同参数再次出现时仍重新计算"。
- **定义**：`fib(0) = 0`，`fib(1) = 1`，其余为两项之和。
- **演示输入**：`fib(5)`，最终得到 `5`。
- **时长**：约 49 秒（预算 42～50 秒）。
- **声音**：无配音、无背景音乐。

## 正确性基准

- 最终值 `fib(5) = 5`
- 调用总数 15 次，基础情况 8 次，非基础 7 次
- 完整树 15 个节点、14 条父子边
- 参数出现次数：`5`×1、`4`×1、`3`×2、`2`×3、`1`×5、`0`×3
- 最大同时存在的调用 5 层（`5 → 4 → 3 → 2 → 1`）

## 执行顺序（关键）

固定采用**先完整算完左子树，再进入右子树**：

```
fib(5)
├─ fib(4)
│  ├─ fib(3)
│  │  ├─ fib(2) → fib(1)=1, fib(0)=0 ⇒ 1
│  │  └─ fib(1)=1                    ⇒ 2
│  └─ fib(2) → fib(1)=1, fib(0)=0 ⇒ 1 ⇒ 3
└─ fib(3)
   ├─ fib(2) → fib(1)=1, fib(0)=0 ⇒ 1
   └─ fib(1)=1                      ⇒ 2 ⇒ 5
```

节点 id 就是真实进入顺序；同参数的多次调用是不同的节点，不合并、不缓存。

## 分镜

| 场景 | 时间 | 内容 |
|---|---|---|
| 一 | 0～2 s | 标题 + `fib(5)` + "看清调用与返回" |
| 二 | 2～6 s | C++ 六行代码，光标依次停在边界 / 左调用 / 右调用 / 求和 |
| 三 | 6～18 s | `5→4→3→2` 向下调用，第一次完整的"边界 → 返回 → 求和"（全片最细，长停顿） |
| 四 | 18～40 s | 按真实顺序完成剩余调用，重现多个同参数调用 |
| 五 | 40～45 s | 回顾：三个 `fib(2)`、五个 `fib(1)` |
| 六 | 45～49 s | `fib(5) = 5`，时间上界 `O(2ⁿ)`、栈空间 `O(n)` |

`O(2ⁿ)` 是上界；更紧的界是 `Θ(φⁿ)`（φ 为黄金比例），本片为保持简洁只展示上界。
